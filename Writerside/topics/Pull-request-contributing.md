## How to Contribute

If you want to contribute please follow the steps bellow:

1. Create fork of the repository
2. Clone your fork
3. Create a new feature branch
4. (Optional) Create a [Draft](#drafts-optional)
5. Commit your changes
6. Create a [feature pull request](#feature-pull-requests)

## Pull Requests

### Drafts (Optional)

For working closely together creating a draft on the start of a feature development is a good way to have others access 
your code and test or pre-review it if your development is still in progress. This step is not mandatory as you could 
also show your code in person or by any other way.

#### Why a still create draft ?
If you work on multiple project at once, the draft comments section is a good place to leave comments on what is the 
status of your work so you or any other person can easily get back to the code and know what was done and which parts a
still todo.

### Feature Pull-Requests

As you work on a fork of the project it is mandatory for your changes to be merged that you make a pull request. If you
want to you can use the following template for naming and describing your changes in the pull request.

Title: `Feature: <feature name>`

Description: 
```
**description**
simple description of your feature

**changelog**
- List of changes as a simple fielded version of the commit history
- ...
```
